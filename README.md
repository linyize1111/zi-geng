# 字耕（Zi Geng）

私人向學習／寫作 PWA：`https://linyize1111.github.io/zi-geng/`

## 本機

```bash
cp .env.example .env.local   # 開發可設 VITE_USE_MOCK_ADAPTER=true
npm install
npm run dev
```

品質檢查：`npm run ci`

- `docs/PROGRESS.md` — 目前進度
- `docs/USER_ACTIONS_REQUIRED.md` — 需你手動的項目
