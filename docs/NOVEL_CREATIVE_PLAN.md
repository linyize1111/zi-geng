# 小說創作計畫系統

字耕的「小說任務」不是隨機靈感碎片，而是一套可重複的創作節奏。完整章節大綱由你稍後提供；在此之前以**目前構思**填寫專案欄位即可。

## 階段

1. **構思** — logline、主題句、類型／讀者約定、核心衝突、不可妥協設定  
2. **世界** — 壓力來源、日常／例外、資訊落差  
3. **角色** — want／need、對手理由、秘密、配角欲望、權力斜率、聲音  
4. **情節** — 不可逆事件、三幕骨架（待大綱覆寫）、結局代價、因果鏈  
5. **場景** — 利害、進出場、功能標籤、感官錨  
6. **草稿** — 單場推進、對話場、過渡壓縮、開場三稿  
7. **修訂** — 主題回聲、刪愛、動機一致性、讀者問題  

## 大綱保留區

小說專案編輯頁有「大綱（保留區・待你貼上）」：

- 先留空不影響今日任務  
- 貼上大綱後，狀態會變成草稿；可再跑標了「待大綱」的任務覆寫情節骨架  
- 把大綱傳給助手時，也會以此區為準對齊任務
